# CA1 – Clustering and Time Series Forecasting of Apple (AAPL) Stock

Achraf Bahri – 2026167 | Machine Learning for Business | CCT College Dublin

## Files
- `CA1_Achraf_Bahri_2026167.ipynb` – notebook (data cleaning, K-Means and Agglomerative clustering, ARIMA forecasting)

## How to run
Open the notebook in Jupyter and run all cells. The notebook reads the CSV from the same folder.
